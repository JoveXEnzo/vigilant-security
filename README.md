# Vigilant Proprietary Security Website

Professional security services site for Upland & Anaheim, CA. Offers armed guards, patrols, event security.

## Features
- Responsive design (mobile-first)
- Parallax hero with high-tech background
- Interactive service flip cards
- Contact form with validation & submission
- Stats section with industry data
- Sticky navbar with mega dropdown
- Testimonial slider
- Dark mode toggle
- SEO meta tags & accessibility

## Setup
1. Clone repo.
2. Add images to /images/ (optional; external URLs used).
3. Open index.html or host on GitHub Pages/Netlify.
4. For form: Replace Fetch URL in script.js with your backend (e.g., Formspree).

Built with HTML/CSS/JS. No frameworks for simplicity.
